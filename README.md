# Boardoza MLX90640 Thermal Camera Breakout Board

The **Boardoza MLX90640 Breakout Board** is a compact and high-performance **thermal imaging sensor board** built around the **Melexis MLX90640** far-infrared sensor array. Featuring a **32x24 pixel thermal resolution**, this breakout board delivers **768 independent temperature measurement points** for accurate non-contact thermal analysis and heat mapping applications.

Designed for compatibility with both **3.3V and 5V systems**, the board communicates through a high-speed **I<sup>2</sup>C interface** and supports refresh rates up to **64Hz**. With its wide temperature sensing range and integrated thermal array, the MLX90640 is ideal for applications such as industrial monitoring, predictive maintenance, occupancy detection, smart home systems, thermal visualization, robotics, and embedded sensing solutions.

## Key Features

- **32x24 Thermal Imaging Array:** Captures 768 individual infrared temperature points for detailed thermal analysis.
- **Wide Temperature Measurement Range:** Measures object temperatures from **-40°C to +300°C** without physical contact.
- **Integrated Thermal Camera Functionality:** Enables compact thermal vision applications without requiring external optics.
- **Fast Refresh Rates:** Adjustable frame rates from **0.5Hz to 64Hz** for dynamic thermal monitoring.
- **Wide Compatibility:** Supports both **3.3V and 5V logic systems** for easy integration with popular development boards.
- **I<sup>2</sup>C Communication:** Supports I<sup>2</sup>C speeds up to **1MHz** for responsive thermal data transfer.
- **Wide Field of View:** Provides a **55° horizontal (X-axis)** and **35° vertical (Y-axis)** viewing angle for broader thermal coverage.

## Technical Specifications

**Model:** MLX90640  
**Manufacturer:** Boardoza  
**Manufacturer IC:** Melexis  
**Functions:** Far-Infrared Thermal Imaging Sensor Array  
**Sensor Resolution:** 32 x 24 Pixels (768 Pixels Total)  
**Measurement Range:** -40°C to +300°C  
**Field of View (FoV):** 55° (X-axis) × 35° (Y-axis)  
**Interface:** I<sup>2</sup>C  
**I<sup>2</sup>C Clock Speed:** Up to 1 MHz  
**Refresh Rate:** 0.5Hz to 64Hz  
**Supply Voltage (VCC):** 3.3V to 5.5V DC  
**Logic Voltage Level:** 3.3V / 5V Compatible  
**Typical Current Consumption:** Less than 25mA   
**Operating Temperature:** -40°C to +85°C  
**Board Dimensions:** 20mm x 20mm
